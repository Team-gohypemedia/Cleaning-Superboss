# Cleaning Superboss

Premium, technology-driven cleaning company and smart cleaning platform.

## Features
- **3D Canvas Morphing & Interactive Scroll**: Frame-by-frame 3D transitions for hero and platform storytelling.
- **Dynamic Services & Animated Modal**: Interactive service catalog with before/after bento gallery.
- **Smart Automated Booking & Instant Quote**: Full pricing calculation and fast scheduling modal.
- **Interactive Shuffling Testimonials**: 5-star verified client reviews with auto-rotation.
- **Modern Clean & Energetic Aesthetic**: Built with Next.js 16, Tailwind CSS, Framer Motion, and GSAP.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
